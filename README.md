# Temperature_prediction
# Temperature Prediction Using Machine Learning

## Project Overview

This project focuses on predicting temperature based on humidity data using Machine Learning techniques. A Linear Regression model was implemented to analyze the relationship between humidity and temperature and generate accurate predictions.

The project demonstrates the complete machine learning workflow including data loading, preprocessing, exploratory data analysis, model training, evaluation, and prediction.

---

## Objective

To build a regression model capable of predicting temperature values using humidity as the input feature.

## Dataset Overview

The dataset contains humidity and temperature readings used to train and evaluate the regression model.

### Features

* **Humidity** → Input feature
* **Temperature** → Target variable

---

## Workflow

1. Import required libraries
2. Load and inspect dataset
3. Perform Exploratory Data Analysis (EDA)
4. Handle missing values
5. Split data into training and testing sets
6. Train Linear Regression model
7. Predict temperature values
8. Evaluate model performance using:

   * Mean Squared Error (MSE)
   * R² Score

---

## Model Used

### Linear Regression

A supervised machine learning algorithm used for predicting continuous numerical values based on relationships between variables.

---

The model successfully learned the relationship between humidity and temperature and generated predictions with evaluation metrics such as:

* Mean Squared Error (MSE)
